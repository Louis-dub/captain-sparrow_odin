# Captain Sparrow's Black Pearl - The Odin Project

## Description

This project is part of [The Odin Project](https://www.theodinproject.com) curriculum. This project is a simple web application that serves as a personal website for Captain Jack Sparrow, the famous pirate known for his adventures on the Black Pearl. The website includes pages for the home, about, and contact sections.

## Features

- **Home Page**: Welcomes visitors aboard the Black Pearl.
- **About Page**: Provides information about Captain Jack Sparrow and his adventures.
- **Contact Page**: Allows visitors to get directions to meet Captain Jack Sparrow in Tortuga.

## Technologies Used

- **HTML**: For structuring the web pages.
- **CSS**: For styling the web pages.
- **NodeJS**: For handling interactions, such as opening Google Maps for directions.

## Project Structure

- **index.html**: The main entry point of the web application.
- **about.html**: The about page with information about Captain Jack Sparrow.
- **contact.html**: The contact page with a button to get directions to Tortuga.
- **index.js**: The main server file that handles HTTP requests.
- **package.json**: Contains project metadata and dependencies.
- **public/**: Directory containing the CSS and image files.
  - **styles.css**: CSS file for styling the web pages.
  - **logo_sparrow.jpg**: Image file for the logo.

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone git+https://github.com/Louis-dub/captain-sparrow_odin.git
   ```
2. Navigate to the project directory:
   ```bash
   cd captain-sparrow_odin
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   node index.js
   ```
5. Open your web browser and navigate to `http://localhost:8080` to view the website.

## Usage

- **Home Page**: Navigate to the home page to see a welcome message and a button to get on board.
- **About Page**: Navigate to the about page to learn more about Captain Jack Sparrow.
- **Contact Page**: Navigate to the contact page to get directions to meet Captain Jack Sparrow in Tortuga.
